# Docs

This directory is a placeholder.

The API contract fixtures will be copied here, unedited, from the web repository's
`docs/cms-fixtures/`. They are not written by hand in this repository: the web repository
is the contract, and a fixture invented here would test the plugin against an API that
does not exist. A CI check will compare the copies with a pinned commit of the web
repository once the fixtures exist (CMS API 3).

The design is in the web repository's `docs/PLAN-cms-modules.md`.
